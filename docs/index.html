MARKET PULSE

원료 가격은 방향만, 판단은 근거와 함께.

국제 옥수수·대두 가격을 보조 신호로 사용합니다. 수집 실패 시 이전 값 또는 ‘확인 대기’를 명시합니다.

03 · UNIT ECONOMICS

가정은 숫자가 아니라 검증 상태로 관리합니다.

가격·투입량·원가는 모델 값입니다. 견적서와 시험 결과가 연결되기 전에는 확정값이 아닙니다.

핵심 변수현재 값상태계산/근거다음 검증
04 · 90-DAY ROADMAP

90일 안에 ‘계속할 이유’를 증명합니다.

규제 → 공급·경제성 → 고객 증거 순서로 자본 투입을 단계화합니다.

05 · OPERATIONS

자동 수집과 사람의 판단을 분리합니다.

공개 원천은 정기 수집하고, 검토 완료 근거만 준비도 점수에 반영합니다.
