# 가바케어믹스 제품 규격서

## 제품 정의

가바케어믹스는 가바크루드와 미네랄매트릭스를 조합한 축종별 배합사료 설계안입니다.

## 기준 설계

| 항목 | 기준값 | 확인 방식 |
|---|---:|---|
| 구성 | 가바크루드 + 미네랄매트릭스 | 배합표·배치기록 |
| 투입 기준 | 75g/사료 t (사업 가정) | 축종별 유효용량 시험 |
| 적용 축종 | 소·돼지·육계·산란계·염소·면양 | 축종별 대조시험 |
| 최종 규격 | 시험 전 미확정 | CoA·안정성·기호성 확인 |

※ 75g/사료 t는 검증 전 사업 가정입니다. 실제 투입량과 표시 문구는 축종별 시험 및 규제 검토 후 확정합니다.
