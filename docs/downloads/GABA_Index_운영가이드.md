# GABA 사료 비즈니스 모델 인덱스 운영가이드

기준일: 2026-08-03  
현재 단계: **VALIDATE · 준비도 41/100**

이 인덱스의 목적은 시장·정책·제품근거·원가·고객검증을 한곳에 모으고, “확인된 것”과 “아직 가정인 것”을 분리해 다음 행동을 결정하는 것입니다. 투자등급이나 제품 효능등급이 아닙니다.

## 1. 파일별 역할

| 파일 | 언제 사용 | 핵심 역할 |
|---|---|---|
| `GABA_Index_Master.xlsx` | 매주·매월 운영회의 | 점수, 근거, 원가, 용어, 변경 이력을 갱신하는 원장 |
| `GABA_Business_Model_Index.html` | 상태 확인·내부 공유 | 결론, 준비도, 정책·논문 신호, 원가 가정을 한눈에 보는 대시보드 |
| `GABA_Feed_Business_Model_Speech_Deck_v1.pptx` | 사료업체·투자자 미팅 | 20% 마스터 1 SKU + 주문 후 OEM 모델을 설명하는 19장 발표자료 |
| `GABA_Index_Artifact.json` | 대시보드 재생성 | 대시보드의 구조와 현재 스냅샷을 담은 유지보수 원본 |

## 2. 처음 보는 사람의 5분 사용법

1. `GABA_Index_Master.xlsx`의 `00_Start`를 열어 준비도, 현재 단계, 긴급 검증 게이트를 확인합니다.
2. `01_Readiness`에서 가장 낮은 축과 열린 게이트를 찾습니다.
3. `02_Source_Register`에서 해당 판정의 근거 URL·파일과 다음 행동을 확인합니다.
4. 가격·원가·용량을 논의할 때는 `03_Unit_Economics`의 주황색 입력값이 실제 증빙으로 바뀌었는지 확인합니다.
5. 외부 공유 전에는 `05_Update_Log`와 마지막 `99_Appendix`의 면책을 확인합니다.

## 3. 업데이트 주기

### 매주 15분

- 새 정책·논문·고객 피드백·OEM 견적을 `02_Source_Register`에 한 줄씩 추가합니다.
- 날짜, 판단, 다음 행동, URL/파일, 주의사항을 반드시 함께 기록합니다.
- 숫자나 결론이 바뀌면 `05_Update_Log`에 “무엇이 바뀌었고 어떤 결정에 영향을 주는지”를 남깁니다.

### 매월 45분

- 농식품부 공고, 국가법령정보센터의 사료 기준·규격, KREI 국제곡물 관측을 확인합니다.
- 옥수수·대두박·해상운임과 OEM 견적을 최신화합니다.
- 다섯 평가축의 증빙을 다시 보고 `01_Readiness` 점수를 갱신합니다.
- 점수는 말이나 추정만으로 올리지 않습니다. 파일·URL·기준일·결론이 연결될 때만 올립니다.

### 분기별 의사결정

- **EXPLORE 0~39:** 문제·가설 탐색
- **VALIDATE 40~59:** 규제경로·제품정의·OEM·유료 고객 검증
- **PILOT 60~79:** 고객·공장 실증
- **SCALE 80~89:** 반복주문과 공급 복제
- **READY 90~100:** 투자·계약 검토에 사용할 감사 가능한 데이터룸

현재는 41점이므로 대규모 재고·설비 확대보다 네 게이트를 잠그는 데 예산을 우선합니다.

## 4. 네 개의 긴급 검증 게이트

| 게이트 | 잠금 해제 증빙 | 실패 시 |
|---|---|---|
| 규제·품목분류 | 관할기관/전문가의 사전검토, 등록경로, 표시 가능 문구 | STOP |
| 제품근거·유효용량 | 제품특이 활성함량, CoA, 안정성, 축종·제형·용량이 고정된 유료 PoV | HOLD |
| OEM·QA | 제조사 2곳 실견적, MOQ, 리드타임, QA Agreement, 추적·회수 체계 | HOLD |
| 상업검증 | 첫 유료 PO, 반복주문 트리거, 반복 PO 증빙 | STOP |

## 5. 원가 모델 사용 규칙

- 18,000원/kg, 9,240원/kg, 75g/사료t, 4,681.8원/kg, 고객가치 18,000원/사료t은 원본의 입력 가정입니다.
- 9,240원/kg은 배양·건조·부형제·시험·포장·수율의 비용 브리지가 연결돼야 합니다.
- 75g/사료t은 제품 투입량인지 활성 GABA 투입량인지 먼저 확정해야 합니다.
- 고객가치는 유료 대조군 PoV에서 경제효과를 측정하기 전에는 영업·투자 확정치로 표현하지 않습니다.
- 외부 제안에는 항상 `시나리오`, `가정`, `검증 완료` 중 하나의 상태를 표시합니다.

## 6. 90일 실행 순서

### 0~30일 · 경로 잠금

- 품목분류·등록경로·표시 가능 문구 사전검토
- 제품 활성함량·제형·로트 규격 확정
- OEM 후보 2곳에 RFI 발송

### 31~60일 · 제품 잠금

- 시험생산, 균일도, 안정성, CoA, 공장 적합성 확인
- 축종 하나·제형 하나·1차 지표 하나의 유료 PoV 프로토콜 합의
- 실제 견적을 `03_Unit_Economics`에 반영

### 61~90일 · 상업 잠금

- 첫 유료 PO 확보
- 반복주문 조건과 중단 기준을 계약서에 반영
- 실제 원가·공헌·공급능력으로 GO/NO-GO 결정

## 7. 외부 미팅 전 체크리스트

- 발표 첫 문장은 “20% 마스터 1 SKU만 재고로 두고 주문 후 OEM 생산한다”로 통일합니다.
- 확정 사실, 학술 신호, 내부 가정을 섞지 않습니다.
- 축종·제형·용량이 다른 연구를 제품 효능 보장으로 표현하지 않습니다.
- 저탄소 정책을 언급할 때 GABA 제품이 지원 대상이라고 단정하지 않습니다.
- 수익성은 실제 OEM 견적과 유료 PO가 연결된 버전만 사용합니다.
- 마지막 장은 항상 Appendix로 유지합니다.
